HeartLink Pipeline Dashboard

Information:

HeartLink is a reproducible machine learning pipeline for heart disease analysis using the UCI Heart Disease dataset (920 patients, 4 hospitals). This dashboard presents the pipeline outputs across three complementary analyses.

Classification

Binary prediction of heart disease presence using Random Forest. Evaluates accuracy, precision, recall, F1, and AUC-ROC.

Regression

Predicting maximum heart rate (thalch) across 8 dataset variants to quantify cardiac functional decline.

Clustering

Unsupervised patient risk group discovery using KMeans with PCA dimensionality reduction.
