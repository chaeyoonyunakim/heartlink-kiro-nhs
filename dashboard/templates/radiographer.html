Zero-Value Entry Flags

Important: Zero-Value Interpretation Guide

A zero value in diagnostic fields can mean different things depending on the variable. The guardrail system flags these for your review.

ca = 0 (Major Vessels)

Valid clinical finding

Zero major vessels coloured by fluoroscopy is a legitimate result indicating no significant coronary artery narrowing was observed.

172 records with ca = 0 in the dataset.

thal = 0

Likely recording error

Thalassemia type 0 is not a valid clinical category. Valid values are: normal (3), fixed defect (6), reversible defect (7). A zero likely indicates the test was not performed or the result was not recorded.

7 records with thal = 0 in the dataset.

slope = 0

Ambiguous — review needed

Slope values are typically coded 1 (upsloping), 2 (flat), 3 (downsloping). A zero may indicate the ST segment was not assessed during exercise testing, or it may be a coding artefact.

0 records with slope = 0 in the dataset (after exclusion).

Recording Guidance

Do

  • Record ca = 0 when fluoroscopy confirms zero vessels with significant narrowing
  • Use the correct thal coding: 3 (normal), 6 (fixed defect), 7 (reversible defect)
  • Leave the field blank (not zero) if the test was not performed

Don't

  • Do not enter 0 for thal when the test was not performed
  • Do not use 0 as a default when equipment fails — record as missing instead
  • Do not skip slope recording during exercise testing — it is a key predictor
